# Oxenfree 한글패치 + 김쥬크 설치기 작업노트 (2026-11-16)

## 1. Oxenfree 한글패치 (완료, 실게임 확인 대기)
- 최신 스팀판(Unity 6000.0.59f2)에 넷플릭스판 공식 한국어가 이미 들어 있음.
  대사, 선택지·UI 3,967항목, 지도 이미지, 한글 폰트(Cute Font, 기본 폰트의 대체 폰트로 연결됨)
- 스팀판은 언어 목록(Dialog.supportedLanguages)에 한국어가 없어서 못 고름
- 패처가 하는 일 (Assembly-CSharp.dll 하나만 수정, 원본은 .ko_backup으로 백업)
  1) 언어 목록 7번째 칸(러시아어=30) → 한국어(23)
  2) MainMenu/PauseMenu.Start에서 언어 드롭다운 값을 정한 직후
     Dialog.__KoFixDropdown(dropdown)을 호출해 그 칸 글자를 "한국어"로 바꿈
  3) 레지스트리 HKCU\Software\Night School Studio\OXENFREE
     text_language_h2258702997 = 6 (DWORD) → 처음부터 한국어로 시작
- 코드를 이름으로 찾아 고치므로 스팀 업데이트 뒤에는 다시 실행만 하면 됨
- 이미 겪은 문제: Mono에서 가져온 Mono.Cecil.dll이 .NET Framework에 없는 API 3개
  (Array.Reverse<T> 2종, String.Split(char, options))를 써서 윈도우에서 오류
  → fix/fixcecil.cs로 교체해서 해결(4.8 기준 누락 0개). 설치기용은 강력한 이름 서명도 제거(fix/strip.cs)
- **남은 일: 사용자가 실제 게임에서 한국어가 나오는지 확인**

## 2. 김쥬크 설치기 (진행 중)
- 목표: 주크박스 그림 스킨을 쓰는 나만의 설치 프로그램. Oxenfree에 먼저 적용하고, 다른 한글패치에도 재사용
- 결정된 것
  - 그림: Gemini가 새로 그린 주크박스(images/jukebox_gemini_v2.webp) 사용. 밝은 단색 배경이라 외곽 떼어내기 쉬움
  - 버튼 5개: A~E 글자를 지우고 설치 / 복원 / 폴더 / 실행 / 닫기 로 프로그램이 직접 씀 (사용자 확답 전 기본안)
  - LED 5개: 마우스 올림/성공/실패 표시
  - 창: 테두리 없는 주크박스 모양(레이어드 윈도우, 바깥 투명), 드래그로 이동, Esc로 닫기
  - Mono.Cecil을 exe 안에 넣어 파일 하나로 배포
  - 패처 실행 화면(박스) 안에 "By.김쥬크" 표기는 OK, zip 파일 이름에는 넣지 않음
- 만들어 둔 것
  - gui/Patcher.cs : 패치 핵심 로직(화면과 분리, 스팀 라이브러리 자동 탐색 포함)
  - gui/build_skin.py, gui/seg.py : 첫 번째 그림을 코드로 늘려 맞춘 시도(새 Gemini 그림으로 대체 예정)
- 다음 할 일
  1) 새 그림에서 배경 제거 + 화면/버튼/LED 좌표 측정 → Layout.cs 생성
  2) 버튼 글자 지우기
  3) MainForm.cs(레이어드 윈도우, 버튼, 화면 글씨, 진행 기록) 작성
  4) .NET Framework 4.8 API 검사 후 컴파일, 게임 폴더에 배포
- 참고: 오른쪽 기둥 아래 Gemini 생성 표시(✦)가 그림 위에 겹쳐 있음

## 3. 빌드 환경 메모 (클라우드 작업공간)
- conda-forge의 mono 6.12 (mono/bin/mcs, monodis, ikdasm)
  압축 해제 후 bin/ 스크립트 안 placehold 경로를 실제 경로로 바꿔야 실행됨
- 컴파일: mcs -sdk:4.5 -codepage:utf8 -r:Mono.Cecil.dll ...
- API 검사: fix/check.cs (lib/mono/4.8-api 기준)
